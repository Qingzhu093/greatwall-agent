# 执行约定与提示词

## 文件布局

以下为将来运行时的布局约定，不表示本目录已经启动实验：

```text
run/
  brief.md                 # 目标、约束、预算、评价方式
  frontier.md              # 当前成果、活跃路线、开放问题
  tasks.jsonl              # 每项动作的输入、执行位置、额度与结果引用
  decisions.md             # 关键资源选择及其理由
  results/R001.md          # 一项可被继承的发现
  evidence/E001/           # 推导、脚本、实验输出
  workers/W01/             # 独立实现空间或 Git worktree
  deliverable/             # 当前已确认可用的成果引用或快照
```

主持写队列、前沿与预算记录；执行者只写自己的目录及待提交报告。接收成果时由主持保存卡片和证据引用。首版无需实现所有成员并发修改同一张表。

卡片是交接工具。问题很简单时可以直接在报告里写清信息，不要求为了填字段制造内容。

## 研究动作模板

```yaml
id: A007
question: 从 R003 的特殊情形出发，能否得到一个无需已知信号源个数的停止条件？
mode: develop                 # advance / develop / combine
inputs: [R003]
operation: 先构造最小反例，再推导满足明确假设的充分条件
budget: 本轮模型与工具成本上限；墙钟上限
deliverable: 条件、证明或反例、验证脚本；不要求完成整个求解器
```

完成时附实际消耗、产物位置和简短后续提议。任务状态只用 queued / running / done / parked；done 表示动作已结束，不表示研究问题已解决。结论强度写在成果中。

## 成果卡模板

```markdown
# R004：在已知接收半径下界条件下的候选集排除规则
种类：待证猜想 / 推导 / 实验发现 / 组件 / 文献方法
内容：精确表达结论或组件作用。
条件：在哪些任务、数据、参数或假设下成立。
证据：推导、运行命令、结果文件或外部论文页码。
来源：动作 A007；父成果 R003；代码版本或固定产物位置。
局限：尚未证明或测试的部分。
可继续：一个推广问题；一个可能的组合对象。
```

首版不用把这些字段变成复杂模式校验。关键是能让另一个会话接着做，并能够找到证据。

## 主持提示词

> 你主持一项有限预算研究。依据研究简报、成果前沿和剩余额度，选择少量下一步动作。你可以推进当前最佳方案、发展暂时无直接收益的发现，或组合不同路线的成果。
>
> 对尚未获得有效检验的路线留出一次机会。不要因为某路线先返回就持续把所有资源给它。新颖性应体现为新机制、新表示或新证据。
>
> 给动作明确的问题、相关起点、额度和产物。发现式动作可以探索邻近问题，不必承诺提高最终得分。动作结果回来后区分：可交付成果是否改善；下一轮是否多了新的研究起点。
>
> 更新前沿时写出：当前可用成果；值得继续的非冠军发现；重要分歧；下一批动作及资源理由。遇到缺少证据的地方保留问题。把成本和交付时间计入选择。

## 执行者提示词

> 围绕给定研究问题工作，优先做能够产生实质内容的推导、检索或实验。你可以改变实现和问题表述；如主要问题已经改变，说明原因。
>
> 提交可以让他人继承的产物、适用条件与证据。局部结果、反例和有效工具都有价值；清楚区分已建立结论和猜想。文献引用到原始来源，说明哪些部分由你复现。
>
> 当出现意外但有内容的发现，保留它并提出一个小的后续问题。完成本额度后说明下一步值得做什么及其理由。

## 证据审阅提示词

> 判断本次结论在所写条件下获得了什么支持。聚焦会改变研究判断的关键问题；设计最小的判别实验或检查关键推导。
>
> 给出：证据支持的内容；仍开放的内容；最有价值的一项补充工作。研究续投和最终采用分别表达。不要以文风、代码保守程度或自评置信度代替实际证据。

## 组合提示词

> 阅读两项成果的具体内容与条件，指出一个可以连接的机制。明确谁输出什么、谁使用什么，以及连接后增加了什么能力。
>
> 尝试一个最小组合，比较它与相关父方案。若连接不成立，指出不相容的条件；若只有思想能迁移，给出新的实现。保存组合依据和测量结果。

## 主循环伪代码

```text
读取简报，建立参考方案和初始问题
预留最终确认额度，分配初始独立探索额度
while 仍有研究预算且存在值得执行的动作:
    接收已完成动作，记录实际消耗与成果
    按证据更新当前交付候选和研究前沿
    如果有重要成果或已完成一小批动作:
        提出一次相关成果交换或组合
    如果存在空闲执行席位:
        比较下一批候选动作
        考虑累计预算用途和各路线已获得的机会
        派发一个有明确额度的动作
停止派发，整理已完成与尚未完成的研究
用预留额度比较最终候选，输出结果、证据与开放问题
```

没有可用的异步/并发接口时按同一规则串行执行。逻辑上保留多个研究起点，不要求物理同时运行。

## 五小时试运行的人工配置示例

总墙钟 300 分钟；先给最终确认和整理留约 45 分钟。研究段 255 分钟作为计划窗口，同时设模型实际成本上限，并按先触及的上限结束。并行会话的运行分钟总和可以大于墙钟窗口，因此不能用“每支分配 85 分钟”代替成本控制。

先建立基线及两三条问题路线；第一次有实质结果后安排成果发展；出现可连接内容后安排组合。主持在若干动作完成时重新估计预算，避免长篇计划和报告占据主要调用。此处数字仅用于首次实验，之后根据测量调整。
