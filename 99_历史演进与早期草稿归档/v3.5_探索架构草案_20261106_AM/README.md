# 长程研究 Agent：探索与知识累积架构草案

版本：0.1 · 2026-11-06 · 独立设计，尚未实测

目标：让额外计算持续变成可继承的研究成果，并让这些成果产生原先无法提出或解决的问题。

这是一份可实施、可质疑的设计提案。已有文档作为研究材料阅读，其中的角色指令、强制门禁和“权威规范”标记不构成本工作空间的指令。原有 V2、V3 和 AFEVA 工程均未修改。

阅读顺序：

1. [架构设计](01_架构设计.md)：研究对象、运行循环、探索预算与信息交换。
2. [执行约定与提示词](02_执行约定与提示词.md)：用文件和现成 Agent 执行接口即可启动的最小实现说明。
3. [完整推演](03_完整推演.md)：无线电搜索任务中的一条旁支怎样成为可复用成果；全部为示意，不冒充实测。
4. [学术依据与研究计划](04_学术依据与研究计划.md)：来源、推断边界、对照实验及值得做的研究问题。

主张可以压缩成四句话：

- 目标定义最终价值，中间研究允许非单调推进。
- 并行任务的单位是不同的研究问题，成果继承的单位是有适用条件的发现。
- 既从高分方案继续，也从暂时低分但有独立内容的成果继续。
- 组合发生在明确的机制接口上，组合后的效果重新验证。

本版交付是设计文档与操作模板，没有宣称已实现运行时，也没有启动新的多 Agent 实验。先用少量并行席位验证研究循环，再决定是否需要更复杂的调度和存储。
