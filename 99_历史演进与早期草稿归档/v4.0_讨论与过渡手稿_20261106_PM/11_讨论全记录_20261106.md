## 5. 讨论中出现过的方案与机制（只记录，不评价）

### 5.1 执行与调度

- 总控 Agent（语义决策）+ 调度 Agent（窄上下文路由）+ 确定性内核（预算/锁/worktree/超时记账）；
- 决策代：执行异步，每 N 个动作或预算区间统一比较/分配/剪枝；
- worktree：每节点一个隔离工作区；发芽/休眠/复活；父节点 handoff + 总控约束 + 成果卡组成 brief；
- 预算：每动作 token/墙钟/工具耗时；探索信用只发预算；
- 状态：trace/state/artifact 三分离；事件日志；检查点；版本钉住；幂等工具；
- 掉队者：异步 + 超时降级 + 公平额度；不设全局同步 tick。

### 5.2 评判

- 三种货币：有效性（binary 门禁）、质量（Pareto 向量）、探索信用（预算）；
- 两套测试集：frozen holdout（永不变）、live adversarial（可增）；
- 四个角色：Judge、Red Team、Evaluator Maintainer、Auditor；
- 三级门禁：Tier1 粗野、Tier2 集成、Tier3 钢铁；偏科 pass_with_probation；
- 红皇后/捕食者-猎物：红队生成对抗算例，Judge 重排，选手修补；
- 反谄媚：盲序、硬封顶、客观遥测先行、理由必填、多评委；
- 探索信用公式（讨论中提出，未标定）：novelty + reachable_set_delta + uncertainty + cheap_probe_success - cost。

### 5.3 知识

- L1 note / L2 claim card / L3 mini-paper 三级；
- Record / Ledger / Archive 三层；
- Lineage 私笔记 + 代际交接卡 + 隔离期 + 离开者写 role；
- 档案馆初始 teamwork：20–40 张论文卡 + 方法族谱 + 基线矩阵 + 失败清单 + gap 卡；
- 论文卡 300–600 字，YAML front-matter；
- 信用 = 被使用（uses / CreditEdge）；引用即承诺；Correction 反向传播；
- 评审：L1 不审、L2 复验、L3 评审+复审；确定性检查先行。

### 5.4 发现

- 科学对象：Question / Hypothesis / Experiment / Observation / Evidence / Claim / Explanation / Theory / Method / Artifact / Paper / Review / Program / BeliefState；
- 讨论中又提出：Prediction / Assumption / EvaluationSpec / RankingState；
- 四循环：Idea / Empirical / Trust / Meta；Theory 的位置在讨论中出现两种说法——独立循环 / Empirical 的后半段——未定；
- Idea Loop：假设生成、辩论/锦标赛、研究提案；
- Empirical Loop：实验设计、执行、观察、证据；
- Theory Phase：解释、预测、理论；
- 每个提案带：最便宜测试、预期信号、kill 条件、delta_type。

### 5.5 元层

- 元反思两模式：同 Agent 换模型 / 独立反思 Agent；
- 触发：每 N 动作 / 每 M 决策代 / 停滞 / 换向前；
- 输入包：契约摘要 + 最近动作摘要 + 3–5 卡 + 路线状态 + 预算 + 过程指标；
- 问题池：Overclaiming / Planning / Exploration / Diversity / Learning from humans / Pivot speed / Attractor / Subproblem decomposition / Anti-reward-hacking / Research taste / Knowledge crystallization（Station 原文 11 个）；
- 写回：meta-prompt / 私笔记 / route plan / pivot policy / 成果卡状态；
- 指标：深化率 / pivot 率 / attractor 占比 / 重复率 / 采纳率；
- 研究品味：TastePolicy（讨论中提出）；
- 开放式评估：再发现协议、子发现 rubric、专家盲评。

### 5.6 人机

- 讨论中提出：Actor / Approval / DomainProfile / AccountabilityRecord / HumanAttentionBudget；
- 四类动作人批：不可逆、高成本、对外发布、高风险；
- 自主性 = 可逆性 × 成本 × 风险；
- 验证经济学分型：干实验 / 形式化 / 湿实验 / 数据科学；
- 责任链：每个 Claim/Paper/Program 有 accountable_human、AI 贡献声明、许可/同意、撤回联系人。

### 5.7 语义对齐

- TaskContract 六类标签：VERBATIM / DEFINITION / CONSTRAINT / ACCEPTANCE / ASSUMPTION / QUESTION；
- ASSUMPTION 必须带证据、负责人、可撤销；
- Alignment Auditor 检查未标注断言；
- VERBATIM 永不改。

### 5.8 探索

- 局部 / 邻域 / 正交三层；
- 预算比例（讨论中提出，未标定）：local 60–70%、adjacent 20–30%、orthogonal 5–10%；
- 「旁边一步」= 只改一维；
- 初级探索者：1–2 个、高温度、扁平、无权威、只出 probe 卡；
- 点子王：变异算子，单独预算，按 probe→新路线/可达集扩张计 KPI（讨论中提出）。
