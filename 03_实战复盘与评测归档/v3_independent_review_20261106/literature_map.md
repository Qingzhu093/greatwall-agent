**论文阅读地图：哪些能指导设计，哪些适合作为待验证的启发**

检索日期：2026-11-06。只将论文原文、作者项目页和研究机构原始页面作为结论来源。下面的优先级是针对本项目的相关性判断，不是对论文整体价值排名；新预印本的结论需要独立复现。

**第一优先：先读这五篇**

| 论文 | 为什么值得读 | 对本系统的直接启发 | 不能据此推出什么 |
|---|---|---|---|
| [AlphaEvolve，2025](https://arxiv.org/html/2506.13131v1) | 与可自动评估的算法发现最贴近；有实际数学和系统优化成果 | 搜索对象、初始程序、评价反馈及候选档案共同决定发现能力 | 自动评估适用的成功不能直接迁移到开放式科研；不是角色越多越强的证据 |
| [AIDE，2025](https://arxiv.org/html/2502.13138v1) | 提供可理解的代码树基线 | 起草、修复、改进，加相关历史摘要，就能构成完整搜索循环 | 更复杂的岛屿或退火设计必须在同预算下证明额外收益 |
| [MLE-STAR，2025](https://research.google/blog/mle-star-a-state-of-the-art-machine-learning-engineering-agents/) | 把外部知识与有针对性的改进结合 | 先找到有效方法，再通过消融确定值得改进的组件 | ML 比赛上的效果不自动代表通用科学发现效果；应用时应保留本领域基线 |
| [Where Should the Evaluation Budget Go in LLM-Driven Agent Scaffold Evolution? / EvalAlloc，2026-10-27](https://arxiv.org/html/2610.37276v1) | 直接讨论“搜索需要多少评估，最终选择需要多少评估” | 共享少量有区分力的评估条件，保留可比性，集中资源确认最终候选 | 四个 QA/指令遵循基准、两个 scaffold 演化框架的证据，不能直接宣布对所有科研任务最优；目前为预印本 |
| [Long-Horizon Autonomous Architecture Research，2026-08-03](https://arxiv.org/html/2608.01995v1) | 和你实际遇到的平台期、贪心、反复微调最相近 | 研究动作范围、分叉权利和工作流规则会影响探索方式 | 单次运行，没有干净的反事实对照；工具、文献和任务提示的变化存在混杂 |

|---|---|---|---|

**第三优先：最新但尚不宜照单全收的方向**

**Designing Informative Actions，2026-10-31。** 研究动作不能只写“做消融”，还要给出目标、具体干预、重复次数等可执行内容。原文方法节的价值在于把“意图到实验”的信息损失定义得具体。注意其成本是合成单位，实验主要在 30 个合成研究状态上；不是实测 GPU 小时，更不是长程科学发现收益。适合启发一张短实验卡，不需要照搬完整评分模型。[论文](https://arxiv.org/html/2611.00773v1)

**Explore or Confirm?，2026-10-18。** 在简化的有噪声测量环境中，LLM 既可能反复确认而探索不足，也可能只看一次读数就选错。对本系统最有用的是把新候选与复测当作竞争预算的动作。其最小 Agent 配置和模拟 assay 环境与代码科研差别很大，应当把它作为研究假设来源。[论文](https://arxiv.org/abs/2610.25111)

**CATS，2026。** 把 token 与工具调用成本同时考虑，研究串行、并行探索的分配。可作为算力与工具成本统一记账的参照，尤其适合提醒我们不能仅比较运行时长或 Agent 数。证据来自搜索密集任务；这里核对了 Google Research 原始研究摘要，未据此宣称对科研演化有效。[机构原始页](https://research.google/pubs/cost-effective-agent-test-time-scaling-2/)

**CosmosAlpha，2026-11-03。** 用生成谱系、表达式相似性和金融因子相关性构成关系图，提示“跨分支关系”可能比单一父子树丰富。对本项目可先采用极简的“借用了哪个发现”关系，不急着实现整套图传播。论文来自金融因子挖掘，尚不能证明通用长程 Agent 需要关系图。[论文](https://arxiv.org/abs/2611.04555)

**Atlas，2026-10-22。** 把长轨迹连接到目标、决策、产物三层，适合借鉴研究记录的呈现。14 人研究主要支持可理解性和主观负担改善，不是 Agent 求解能力提升的证据；因此不是当前搜索引擎的优先组件。[论文](https://arxiv.org/abs/2610.30548)

**一个老但更接近核心的理论来源。** Hay、Russell 等人的 Selecting Computations 将问题表述为选择能改善最终决策的计算，并讨论它与常规 bandit 最大化累计奖励的不同。科研搜索常常只在最终采用成果时获得主要效用，因此值得先用这个问题定义审视调度，再决定要不要 UCB、MCTS 或退火。[UAI 2012 原始论文入口](https://proceedings.mlr.press/r10/hay12a.html)

**既有文献材料中需要纠正的几个映射**

这些纠偏不否定十条主张，也不意味着原材料都是虚假引用。主要问题是把真实论文中的局部证据扩展成了更强的架构结论。

| 既有说法或映射 | 核对结果 | 建议写法 |
|---|---|---|
| DEI 标为 ICML 2026 | arXiv 明确写的是 SCALE workshop | 标明 workshop，并写清 Core War 与等调用预算 |
| 09 文档部分位置把 CosmosAlpha 对应到 2512.06208 | 该编号实际为 SparsePixels，FPGA 稀疏卷积论文；CosmosAlpha 为 2611.04555 | 统一编号，删除错误映射；[错误编号对应原文](https://arxiv.org/abs/2512.06208) |
| Hu & Zhu 2601.12269 为宏观代码演化退火提供直接依据 | 原论文研究 ToM 与序列概率分布的 MCMC/power sampling，强调无需额外验证 | 作为采样启发，不能写成外部仿真分数下代码变异的验证依据；[论文](https://arxiv.org/abs/2601.12269) |
| MAP-Elites 被表述为 Fitness-Free QD | 经典算法在每个行为区域维护质量较好的解 | 分开“纯 novelty search”和“quality-diversity” |
| ACE 证明手册应硬限 1500–2000 token | 论文强调保留丰富、可增量组织的知识 | 将长度视为实验参数；外部知识库与当前工作上下文分开考虑 |
| 注意力研究被扩写为 Softmax / RoPE 的普适物理不可逆定律 | 核对到的是特定任务和模型上的实证现象；不足以支撑该强断言 | 写“观察到长输入损伤推理，因此测试不同上下文策略” |
| AnnCoder 直接支持超长程科研架构 | 论文存在，主要评价 HumanEval、MBPP 等程序生成任务，还含防御模板组件 | 可参考退火对照，降低它在本项目中的证据权重；不必照搬其模板；[正式论文](https://www.mdpi.com/2073-8994/17/7/1087) |

**论文检索如何进入工作流**

建议每次只围绕当前最影响决策的不确定性检索。检索结果保留四项：论文实际做了什么；证据覆盖什么任务；和当前问题的关键差异；它带来的下一项可执行实验。若一篇论文不能改变下一步行动，可以留作背景，暂不把它变成新模块。

为避免“每看到一篇就加一层”，采用一个朴素的准入标准：新机制是否解释了当前瓶颈，是否有比现有机制更低成本的实现，是否能用小型同预算对照识别它的贡献。这个标准用来选择研究投入，不是运行时门禁。
