## 第一章：系统第一性哲学与五大架构刚性不变量

### 1.1 最高第一性与《工程控制论》学术共同体哲学
1. **AI for Science 最高第一性**：原生面向长周期（10–20 小时）、高并发、无人值守的开放科研攻关，无缝兼容 **形式化数学证明（如 Lean 4）、纯解析推导与构造性反例、多保真度数值物理仿真、多目标 Pareto 前沿** 及无先验标尺开放探索，坚决不在底座中硬编码任何特定赛题规则。
2. **钱学森《工程控制论》品味律**：用极薄底座 + 可插拔插件 + 清晰角色边界构成配合良好的整体，拒绝“几十个错误码与叠床架屋式自动门禁”的过度建模。

### 1.2 五大架构刚性不变量（任何中层代码或课题插件不得违背）
1. **判不了，绝不准判负（根治 `Obs-031` 冤案）**：任何仪器故障、输入键遗漏或宿主崩溃，绝不允许写成 `0` 分或“无改进”，更不得扣除探索者修补配额或推高停滞计数。
2. **隔离靠沙箱，绝不靠砍工具（沙箱平权，根治盲审 0 工具失能）**：安全隔离由 OS DACL + 隔离沙箱目录承担；沙箱内向探索者与盲审官同时大方开放 `pwsh/bash`、Python/SymPy 与证明器插件，让系统跑着验证、而不是瞪眼猜。
3. **只在同一健康版本内比较指标**：跨仪器版本的得分不可比；工程 Bug 修复靠**校准集回归验证**即可直接升版，废除 `tie -> incumbent` 与跨样本计数硬比。
4. **正常科研争议制度自闭环，只有口径歧义才告警人类并亮红灯续跑**：分支合并、局部边界收窄、`REVISE` 返工均由系统制度自闭环，不打扰人；无人值守期间若遇题目根本目标/验收口径重大歧义，后台亮 **`ALERT_AMBIGUOUS_SPEC` 红灯**等人事后处理，同时**按原已签口径继续运行**（绝不死等停摆）。
5. **高并发路径多样性优先于局部早熟指标繁荣**：同题出现多分支聚拢在同一学派且占比 `> 50%` 时无豁免刚性打散，不设任何“近期高产豁免后门”。

### 1.3 核心文献在 v3.0 中的精准定位与纠偏取舍
*(完整本机行号导航见 [`../agent_kb/06_十三篇核心文献工程速查卡与本机源码行号索引.md`](../agent_kb/06_十三篇核心文献工程速查卡与本机源码行号索引.md))*

## 第三章：“一委三部”沙箱平权拓扑、“3 真相 + 2 视图”与四大重构内核

### 3.1 极薄事件总线 × 沙箱平权矩阵（详规见 [`agent_kb/01`](../agent_kb/01_拓扑与制度_一委三部扁平制衡与零偏见总线.md)）
- 全员 **7 大角色契约** 均经 DSH 原生 **`ctx.agents.create()` + `agentCtx.tools.restrict()` + `handle.dispose()`** 拉起一次性无状态短会话，磁盘零过程审批 `.md` 文件。
- **沙箱隔离替代砍工具**：
  - `explorer`：独立 Worktree，保留 `read/write/edit/glob/grep/pwsh/bash`；OS DACL 拒读 DB、隐藏校准集及他脉目录；
  - **`library_verifier`（v3.0 彻底平权）**：不再设 `[]` 空原生工具！每次唤醒挂载**独立空白隔离盲审沙箱**（仅置入脱敏待审代码/脚本/Lean 源码与 `[Obs###]`，OS 物理隔离 DB/B 栏/隐藏集/探索 Worktree/网络），**开放 `read/glob/grep/pwsh/bash`（及 SymPy/Lean 4 插件）**，做到实测复算审稿。

### 3.2 工造司降维重构：科研仪器科（详规见 [`agent_kb/04`](../agent_kb/04_工造司与评测_共享探针_可插拔验证钩子与RQGM受控纪元演化.md)）
1. **统一接口与三档同码**：一切验证器/模拟器/探针实现 `evaluate(artifact, spec, tier) -> {status, verdict, tracks, details}`；同一套代码支持 `probe`（公开样快速诊断不入 `Obs`）、`official`（受控沙箱不可篡改入 `[Obs###]`：有保留集时跑保留集，**无隐藏集的开放发现题跑固定配置+多种子复现集并允许 `OK+UNDECIDED`，由盲审沙箱做独立变种子复现核验**）、`heavy`（先写 `linguistic_prediction` 异步排队）。
2. **四态隔离（判不了绝不判负）**：严格分清 `OK` / `CANDIDATE_ERROR` / `INSTRUMENT_ERROR` / `INFRA_ERROR`。**仪器与基础设施报错零处罚探索者**，同事务开单工造司，连续 `3` 次报错熔断为 `UNHEALTHY`。
3. **校准集回归升级（取代 `BB_eps` 与 `tie -> incumbent`）**：`VERDICT` 仪器上线与升版至少须配 `>= 1` 条毒/回归样本（`PROBE`/`ENV` 可选），**每个校准案例自声明预期 `(expected_status, expected_verdict)`**（如缺入口案例预期 `CANDIDATE_ERROR`，合法零解可作 `gold` 案例预期 `OK+PASS`，绝不将全零写死为全宇宙毒样本）；发现 Bug 先加复现案例，新版 100% 通过即直接上线；分数仅在同一 `(instrument_id, version)` 内对比，重评缺新字段诚实标 `INCOMPATIBLE`。
4. **废除 6 项过拟合死规则**：废除每题必建零号基线、全局 `<5%` 误差门禁、全零/常数解拦截、AST `Q3` 禁 `second_pass`、强制 `[Local-Sweep]` 教条与 `eval_count >= 1` 阻塞门槛。保留探索者 `pwsh` 自主微试探自由。

### 3.3 后勤工作部、G3 看板解耦与无豁免学派分流（详规见 [`agent_kb/02`](../agent_kb/02_后勤与谱系_上下文时钟_一对一伴随_四级分诊与五车道复苏.md)）
1. **时钟与 `0–37%` 极简坚守**：`pressure_tokens / 500,000` 直算；`0–37%` 维持原极简设计（只查外藏 `[R###]`，**必须过 `37%` 元反思提神后才解锁内藏 `L3/L2` 与深层 DAG**）；`70%` 除空跑一字未写崩溃外一律写 DAG 页（带 `evidence_grade`）。
2. **G3 看板解耦**：不搞代码拼装新复杂度，保留伴随“旧看板 + 最新手记”增量合成骨架与 **`max_briefing_chars = 2200` 单一硬限**（五段字数降格为软建议）；将“历代全量死胡同只增不忘”物理归位到 **`lineage_dead_ends` 只追加表**，看板第 4 段仅放当前相关精选 + 查全表索引。
3. **分支级极简调度（G1）**：Parse 0 可选 `question_order`（前序题出现 `FULL_GOAL` `L3` 或人工放行后解锁下题）+ 分支级可选 `requires`（仅接收确定性 `L3-###` 或 `OBS:<instrument_id>:PASS`，只拦本分支，**永不跨分支取并集**；前置被撤回时在跑分支标脏并在交接转 `LEVEL_4B`）；引用边默认改为 **`MOTIVATING_REF`**，仅 Stage 2 盲审升级为 `REQUIRED_PREMISE` 才传播撤回。
4. **动态族谱 & 无豁免聚拢打散（G2）**：交接必填 `<100` 字纯核心机制 `mechanism_summary` 由后勤归类；取消开局强凑 2 路；当任一子题中出现 **`branch_count_in_family >= 2 && share > 0.50`**（删去无意义的 `>= 4` 与一切高产豁免后门），立即强制正交分流。

### 3.4 中央图书馆三态盲审、确证反例入 `L3` 与双段终局（详规见 [`agent_kb/03`](../agent_kb/03_中央图书馆_三本账_两阶段物理盲审_Auditor二次打捞与依赖撤回.md)）
1. **外藏定位明确**：`[R###]` 标定为未复验外部参考摘要；废除缺 `FACT_LOG READ` 强制拒稿降级（仅 Stage 2 参考展示）。
2. **送审与三态裁决**：取消 `passed=1` 硬限，改按主张形态核对可核验载体；送审期间分支处于只读冻结 `PENDING_REVIEW`；Stage 2 按 **`ACCEPT / ACCEPT_NARROWED`（入 `L3` 并显式标注 `goal_coverage`，确证反例与障碍证明带 `NEG_COUNTEREXAMPLE / BARRIER_PROOF` 标签同样入 `L3`）**、**`REVISE`（Stage 1/2 共用 `revise_count`，第 `1–2` 次退回原分支恢复 `ACTIVE_REVISING` 返工，禁 `Auditor` 插手；第 `3` 次仍未过审入 `L2`）**、**`REFUTED`（入 `L2` 雷达，可唤醒 `Auditor` 打捞）**分流；工程崩溃/修补耗尽只入工单与 `lineage_dead_ends`，不污染图书馆。
3. **CDC 双段终局**：`FULL` 要求必答子题存在 `>= 1` 条 `goal_coverage="FULL_GOAL"` 活跃 `L3`；未过 Parse 0 `min_commitment_window` 禁止 Agent 自行申请部分交付退出，必须五车道冲锋；超时且预算见底或人类显式紧急叫停允许导出已审 `L3` 与精确剩余断点，正文严禁混入未过盲审草稿。
