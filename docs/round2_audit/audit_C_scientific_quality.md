### 2.1 `02_works/simulator/core.py`：误差场魔改放大与边缘 25.3%–29.9% 饱和失真

- **源码实证（`02_works/simulator/core.py` L167–182）**：
  ```python

      top = v00 * (1.0 - sx) + v10 * sx
  ```
