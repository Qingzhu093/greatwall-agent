## 一、自适应物理真时钟（`W = min(500k, 模型窗口)`）与单节点四幕生命周期

### 1.1 时钟度量、硬性跑满与为什么不设数值 `eval_count` 前置锁
- **统一自适应物理真时钟**：有效上下文窗口取 **`W = min(500,000, 模型真实物理窗口)`**（既将 1M 等超大窗口封顶在 `500,000` 保持高性价比，又确保 128k/272k 等较小物理窗口模型能顺利抵达 `37%` 与 `70%`）；压力水位由宿主 `TokenMeter` 权威采样并连同 `W` 原子同步至 SQLite `lineage_nodes(pressure_tokens, effective_context_window)`，JS 控制面与 Python MCP 共享同一份 `W` 计算 **`pressure_pct = pressure_tokens / W`**。
- **硬性跑满 `37% -> 70%`（无提前交接后门）**：正常探索不设任何模糊的提前下班判据，必须硬性走完 `37%` 反思与 `70%` 两步清醒交接；仅在遭遇外部不可抗终态（`human_stop`、`closure_allowed`、`abort_node`、DB 节点已被外部关闭）或真报错/断线异常中断（转 `CRASH_RECOVERY`）时才于 `< 70%` 停止。探索循环每轮续推前均通过 `sync_pressure` 核查 SQLite 实时 `node_status`，一旦非活跃立即销毁探索者与伴随句柄释放槽位；待交接/待抢救状态唯一落 SQLite `pending_handoff_mode`。
- **兼容非数值科研**：纯解析数学推导、反例构造或开放理论探索在前 `37%` 窗口内可能全程在做严密推导而不触发数值打分器。因此，**`37%` 元反思与 `70%` 正式 DAG 交接均不要求 `eval_count >= 1`**——只要水位达标即可触发，若到了 `37%` 仍空谈未做任何实质试探，伴随切换外部严苛学者视角时正可借第 7 类路灯效应拷问将其拉回正轨。

### 1.2 单节点同会话伴随暂停续传与四幕完整运行节律

- **单节点伴随会话生命周期（一探索者配一伴随，绝不跨代常驻）**：宿主在单个探索节点生命周期内以保活挂起方式（`keepAliveAfterIdle` + `continueAliveAgent`）仅创建**一个** `lineage_companion` 会话，依次承接 `PRE_SPAWN`（写看板后暂停挂起）$\to$ `REFLECT_37`（传入消息续传后再次挂起）$\to$ `HANDOFF_70`（探索者退场后续传落库），**节点完结即随探索者一同彻底销毁**（绝不跨代常驻以防记忆漂移）。若运行中途宿主重启、保活句柄丢失或触发 `<70%` 断线抢救，控制面自动回退为按 `node_id` 从 SQLite **无状态冷启动**兜底伴随。

| 阶段 | 水位 / 触发条件 | 探索者 (`explorer`) 与伴随助手 (`lineage_companion`) 精确协同协议 |
|---|---|---|
| **第一幕：<br>极简独思净室** | `0% ~ 37%`<br>（`pressure_tokens / W`） | • **轻量启动**：伴随在 `PRE_SPAWN` 写完定额重压缩看板后即暂停挂起；探索者上下文仅注入《谱系状态看板》、上代《遗嘱》、Parse 0 子题契约与 `<worktree>/tools/` 清单，**零全局行政 `.md` 文件读取**；公开题面、数据集与《补充裁决文档》自动挂载在只读 `inputs/`；<br>• **信息隔离**：全程开放公开 `inputs/` 与中央图书馆左翼**外藏 `[R###]`**（基础文献/定理参考）及本 Worktree 自由 Shell 微试验与三档仪器调用；**物理锁定公共内藏 `L3/L2` 与本脉深层 DAG / `lineage_dead_ends`**，让探索者先形成独立视角并撞一次真墙，防止开局盲从跟风。 |
| **第二幕：<br>回合间隙情报型元反思** | `pressure_pct >= 0.37` 且 `first_reflection_unlocked == 0` | • 当前工具调用先正常返回（禁止在工具内阻塞嵌套调子代理）；控制面在**回合间隙**暂停探索者，续传本节点暂停待命的伴随助手进入 `REFLECT_37`；<br>• **情报前置扫描**：伴随调用 `get_companion_context(mode="REFLECT_37")` 同步获取探索者轨迹摘要、**本脉 `lineage_dead_ends` 摘要、同题中央图书馆 `L3/L2` 目录卡摘要**及从 29 题夜科学题库 `1–28` 条中随机抽取的 1–2 道候选；<br>• **《诊断师 + 情报员》尺度红线**：伴随切换外部严苛领域专家人设，完成 **$\le 2$ 轮、每轮 $\le 300$ 字**短问答——允许输出① **基于事实的盲区诊断**（必查第 7 类 `Attractor Tasks` 路灯效应 + 1 项对症元反思）、② **最多 2 条高度相关的 `[L2/L3]` 或死胡同撞车/参考编号指针**（不代读塞爆全文）、③ **1 道夜科学停码追问**；**严守 `AgentDiscover meta.md` 三不给禁令（绝不给算力配额、方案排序表、算法/公式/代码）**，下一步决定权 100% 归探索者；<br>• 问答结束当场调用 `record_reflection_and_unlock_pull` **置位 `first_reflection_unlocked = 1`**，伴随重新暂停挂起，控制面恢复探索者。 |
| **第三幕：<br>开放定向 Pull 攻坚** | `37% ~ 70%`<br>（`first_reflection_unlocked == 1`） | • 探索者带着首轮试错暴露的真实堵点与伴随给出的参考编号指针，自由调用 `query_library_catalog(scope="ALL")` $\to$ `get_library_entry` 两级检索全馆内外两翼（`[R###]` + `L3` 确证库 + `L2` 否定雷达），并调用 `read_lineage_graph(view="nodes"|"dead_ends")` 查阅本门派私有 DAG 祖先页与历代全量死胡同表，深度攻坚直至 `70%`。 |
| **第四幕：<br>两步清醒交接** | `pressure_pct >= 0.70`（硬性跑满） | • **Step 1（亲笔总结与遗嘱归探索者，先落库后销毁）**：控制面在 SQLite 写入 `pending_handoff_mode = 'HANDOFF_70'`，先向仍清醒的 `explorer` 发出最后一轮只读纯文本收官指令——停止改码与跑耗时脚本，命令其亲笔整理本代核心成果、反常线索并撰写《科研遗嘱》（下一步最小鉴别实验、怀疑点与判定翻转条件），**控制面必须先将亲笔原文可靠持久化至 `lineage_nodes.will_md` 后才允许销毁探索者句柄**（若中途重启，`will_md` 非空即原样交伴随续跑 Step 2，为空则转 `CRASH_RECOVERY` 并如实标注原文缺失）；<br>• **Step 2（客观化核对与独占单写落库归伴随）**：续传本节点伴随助手进入 `HANDOFF_70`；**唯有一对一伴随助手拥有 `submit_node_handoff` 独占单写权**（防静默吞稿：仅内容一致时幂等跳过，已闭环节点写入不同新内容硬报 `ERR_LOCKED`），对照探索者亲笔遗嘱、Worktree Diff 与客观 `[Obs###]` 日志，提炼 `<2000` 字客观去人称 A/B 双栏手记 + 遗嘱 + **必填 `<100` 字 `mechanism_summary`** + `evidence_grade`（`NONE / ARTIFACT_ONLY / MEASURED`）+ 本代结构化 `dead_ends`，写入 `lineage_nodes` 与 `lineage_dead_ends` 并置节点为 **`AWAITING_TRIAGE`**，随后伴随会话彻底销毁。 |
| **异常兜底：<br>断线抢救** | `< 70%` 意外断线或超时 | • 控制面立刻在 SQLite 写入 `pending_handoff_mode = 'CRASH_RECOVERY'`（标为 **`interrupted_unclaimed`**）并续传或无状态冷启动 `lineage_companion(mode="CRASH_RECOVERY")` 接管 Worktree：只要**非一字未产空崩溃（`is_empty_crash == false`）**，哪怕未到 `37%` 且无数值 `Obs`，只要留有推导证明稿、反例脚本或阶段代码，一律抢救写入一页正式 DAG（`evidence_grade="ARTIFACT_ONLY"` 或 `"MEASURED"`）并置 `AWAITING_TRIAGE`；仅一字未产空崩溃记入 `scratch_log`。 |

> **错误归因隔离**：仪器返回的 `INSTRUMENT_ERROR` 与 `INFRA_ERROR` 绝对不计入探索者失误、不写入 `dead_ends` 的实现失败、不扣修补配额；探索者自身 `CANDIDATE_ERROR` 与审稿 `REVISE` 异议才转交后续分诊与下代看板。

## 二、真相表与有限看板的物理职责解耦

长程迭代数十代后，历史失败记录必然远超单次启动上下文的字数上限。系统将**“全量永久记忆”**与**“单代焦点视图”**清晰拆分：

1. **历代全量只增不忘 $\to$ `lineage_dead_ends` 只追加表（真相 ②）**：
   - 表字段：`dead_end_id, question_id, branch_id, node_id, category ('SCIENTIFIC_REFUTATION' | 'IMPL_FAILURE' | 'ENV_FAILURE'), scope_condition_md, failure_mechanism_md, bound_obs_id, created_at`。
   - 伴随每次交接同步写入本代新排除边界，永久保留，第 30 代在 `37%` 解锁后仍可查到第 1 代的完整排除档案。
2. **启动扉页摘要 $\to$ `lineage_briefings`（视图 ①，`<= 2200` 字定额滚动重压缩）**：
   - 伴随在新探索者启动前以恒定 $O(1)$ 输入（仅读旧看板 + 刚退场这一页最新手记）执行**定额滚动重写** $\text{新看板} = \text{Rewrite}_{\le 2200}(\text{旧看板},\; \text{刚退场这一页最新手记})$ 并调用 `save_lineage_briefing`（**绝非字符串拼接累加**）；
   - 服务端**唯一硬约束为总长 `<= 2200` 字**（绝不静默切片截断），五段结构作为软参考配比允许伴随按当轮重心自由挪用，重写时必须执行以下腾笼换鸟压缩规则：
     1. **段 1（核心机制，稳定精炼）**：一句话锁定本学派的底层数理不变量与思想路线；
     2. **段 2（已证实前提、快照与 `REVISE` 异议，合并覆写）**：淘汰已被超越的旧基线和过程细节，仅保留一句压缩后的已验证结论、最新物理 `Retained Candidate` 快照，以及若本分支正处于审稿退回返工期（`ACTIVE_REVISING`），必须将仍活跃的 `revision_requests` 置顶高亮；
     3. **段 3（当前核心矛盾，覆盖刷新）**：已解开的旧矛盾压缩并入段 2，段 3 仅留眼下尚未突破的具体引理、边界或物理现象；
     4. **段 4（当前相关死胡同精选 + 全表索引，Top-K 淘汰下沉）**：仅保留与段 3 核心矛盾最直接相关的 Top-K 条反例边界，被挤出 2200 字预算的旧记录已永久保存于 `lineage_dead_ends` 不会丢失，末尾附一行索引（如 `本脉共沉淀 N 条历史排除边界，37% 解锁后可调 read_lineage_graph(view="dead_ends") 查阅全量`）；
     5. **段 5（上代《科研遗嘱》，整体替换）**：直接移除上一代已执行完毕的旧遗嘱，整体替换为刚退场这一代的新《科研遗嘱》（最小鉴别实验与判定翻转条件）。

## 三、分支级极简依赖、动态方法族谱与无豁免刚性分流

### 3.1 两机制极简依赖（绝不跨分支并集锁死）
1. **可选策略题序（`question_order`）**：仅在 Parse 0 由人类按需填写（默认空，全子题并行）；若填写，当前序子题产出至少 `1` 条 `goal_coverage="FULL_GOAL"` 的活跃 `L3`（或被人类显式放行）时，控制面解锁下一子题。
2. **分支级确定性前置（`requires: list[str]`）**：后勤建分支或执行 `fork_branch` 时可选填系统可确定性查库的前置 ID（**仅限两类**：`L3-###` 须为活跃态；`OBS:<instrument_id>:PASS` 须存在有效通过观测）。调度器**只阻断声明了未就绪 `requires` 的这一条分支，绝对禁止将同题不同学派的依赖取并集锁死整题**。若分支已启动后其前置 `L3` 被撤回，标记 `premise_revoked = true`（不强杀运行中会话，待其自然交接时转 `LEVEL_4B`）。

### 3.2 动态方法族谱维护与无豁免 `> 50%` 聚拢打散
1. **机制分类权归后勤**：交接必填 **`mechanism_summary`（`< 100` 字，只陈述底层数学/物理机制、不变量或归约框架，严禁写分数或结果）**；后勤 `triage_node` 对照 `method_families` 表决定归入已有 `family_id` 还是新立正交学派，防止探索者靠换词藻规避归类。
2. **开局不硬凑，运行中持续刚性保障多样性**：开局按人类 Parse 0 思路提示起步（无提示时正常起手）。控制面每次分诊或分支状态变更后，确定性按子题统计各学派活跃分支数：
   - **刚性触发条件**：任意子题一旦出现 **`branch_count_in_family >= 2 && (branch_count_in_family / total_active_branches_in_question) > 0.50`**，立即发射 `FAMILY_CONCENTRATION` 事件唤醒 `logistics_coordinator`；
   - **强制动作**：后勤必须抽调超额分支执行 `fork_branch(fork_mode="orthogonal")` 正交分流至节点最少的学派、阻塞已解除旧学派或新立正交机制——**绝不设“近期高产/高分豁免”后门**，彻底堵死早熟微调吞噬并发槽位。
3. **两级公平分配、学派级阻塞与延迟交叉授粉**：
   - 探索槽位（默认 `6`，硬上限 `10`）先按子题均衡、再在子题内按学派均衡分配；
   - `LEVEL_4B` 默认阻塞本脉及其同前提子支，仅当后勤确认 `blocking_lemma` 属全学派共同前置时标全学派 `BLOCKED`，但后续任意分支只要在 `fork_branch` 声明实质绕开方案 `new_mechanism_note` 即可重开；
   - 跨学派交叉授粉（`fork_mode="cross_pollinate"`）仅在**双方学派各自至少已有 `>= 1` 条已入库 `L3`** 后放行；等价归约（`EQUIVALENT_REDUCTION`）不计入突破。

## 四、`AWAITING_TRIAGE` 硬锁、四级认知分诊与五车道停滞复苏

- **确定性禁抢跑硬锁**：节点处于 `AWAITING_TRIAGE` 且后勤尚未完成 `triage_node` 并刷新 `retained_candidate` 物理快照之前，宿主严禁在该分支启动下一代探索者。
- **六类精确分诊裁决**（先过滤全部 `INSTRUMENT_ERROR / INFRA_ERROR`，零处罚）：
  1. **`ROUTINE_CONTINUATION`**：正常渐进探索与局部边界排除，保持 `ACTIVE` 刷新看板继续推进；
  2. **`LEVEL_1`（突破送盲审）**：满足对应主张形态的可核验载体（详见 [`agent_kb/03`](./03_中央图书馆_三本账_两阶段物理盲审_Auditor二次打捞与依赖撤回.md)）$\to$ 宿主备份物理快照至 `<workspace>/snapshots/<branch_id>/retained_candidate/`，分支置只读冻结 **`PENDING_REVIEW`** 推入中央图书馆 `STAGE1_BLIND`；
  3. **`LEVEL_2`（候选代码原地修补）**：仅针对 `CANDIDATE_ERROR`（假说尚未被真实检验）$\to$ 锁定研究方向，宿主从物理快照恢复工作区原地修补（上限 `3` 次）；满 `3` 次仍败记入本脉 `lineage_dead_ends(IMPL_FAILURE)` 并退回最近健康祖先（**不入公共图书馆 `L2`**）；
  4. **`LEVEL_3`（偏科/反常特异保护）**：主标量暂低或无单一标量，但呈现罕见守恒律、结构反常或 Pareto 单维非支配突破 $\to$ 防伪迹双检后单开保护线深入核查；
  5. **`LEVEL_4A`（严密证伪 / 结构阻碍）**：需附严密反例或阻碍证明 $\to$ 同事务将分支置只读冻结 **`PENDING_REVIEW`** 送盲审：若盲审返 `REVISE` 则切回 `ACTIVE_REVISING` 补证；唯有终判确证 `ACCEPT*`（入 `L3`）、`REFUTED`（入 `L2`）或 `REVISE` 超限时才永久 **`SEALED`**；
  6. **`LEVEL_4B`（缺失定理级引理条件阻塞）**：记 `reopen_condition` 进 `Ready Queue` 暂停，并允许图书馆 `Auditor` 按需打捞残骸中的独立有效引理。
- **全局停滞五车道复苏（`dispatch_stagnation_five_lanes`）**：当主线连续非突破交接达阈值（默认 `8` 次）或全部活跃分支阻塞时，唤醒后勤将活跃分支强制打散编入 `EXPLORATION / EXPLOITATION / REVIVAL / UNDERSTANDING / STRATEGY` 五互斥车道持续破局（未满 Parse 0 `min_commitment_window` 前严禁以停滞为由提前结束任务）。
