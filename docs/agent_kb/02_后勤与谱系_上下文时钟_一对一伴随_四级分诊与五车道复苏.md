## 一、`500,000` 净工作时钟与极简 `0–37% -> 37–70%` 时间轴

### 1.1 物理真时钟与废除 `eval_count >= 1` 硬阻塞（根治第四轮纯推导卡死）
1. **窗口与直算公式**：`context_window_tokens = 500000`，唯一水位度量 **`pressure_pct = pressure_tokens / 500000`**（实时从 `TokenMeter` 同步至 SQLite）。
2. **彻底废除 `eval_count >= 1` 门禁（E2 定案）**：
   - 在纯数学解析证明、构造性反例或未配备自动化打分器的开放任务中，探索者在前 `185k` Token 可能完成的是严谨笔算推导或生成证明手稿，并未调用数值评测；
   - **v3.0 铁律**：到达 **`37%`（`185,000` Token）** 即触发元反思并解锁，**不再卡 `eval_count >= 1`**！若到 `37%` 探索者尚未运行过任何仪器或实质试探，伴随切换外部严苛专家视角时正好以第 7 类 `Attractor Tasks`（路灯效应）与《科研实质推进》当头棒喝；
   - 到达 **`70%`（`350,000` Token）或 `Cost Note`** 时，**无论 `eval_count` 是否为 0，只要有实际推导、反例或实验产物，一律生成一页正常 DAG**（并带 `evidence_grade`: `NONE` / `ARTIFACT_ONLY` / `MEASURED`）。仅“刚启动一字未写即崩溃”的空节点记入 `scratch_log` 跳过看板，彻底删除“零数值实测即作废”条款。

### 1.2 维持 `0–37%` 原有极简设计（坚守元反思防路灯效应底线）
- **第一幕：`0% ~ 37%`（`0 ~ 185k` Token）**：
  - 探索者仅凭 Push 注入的《状态看板》、上代《遗嘱》、Parse 0 契约与 `<worktree>/tools/` 清单起步，**只开放中央图书馆左翼外藏 `[R###]`** 与本 Worktree 自由 `pwsh` 试探（支持调用已挂接仪器的 `probe/official/heavy` 档，**彻底取消 `[Local-Sweep]` 强制格式负担与“必须先本地扫参”条款**）；
  - **公共内藏 `L3/L2` 与本脉深层 DAG / `lineage_dead_ends` 在 `0–37%` 保持物理锁定**，维持原设计极简性，严防小/中模型未经反思即盲从跟风或投机 Reward Hacking。
- **第二幕：`37%` 元反思门禁（`185k` Token，回合间隙顺序切入）**：
  - 控制面在回合间隙顺序暂停探索者 $\to$ 从 29 条夜科学静态题库第 `1–28` 条中**随机抽取 1–2 条候选**推给伴随助手 $\to$ 伴随切换为外部严格领先专家视角，围绕 **必查第 7 类 `Attractor Tasks` + 1 项对症元反思 + 1 条夜科学停码追问** 进行 **2 轮 $\le 300$ 字短问答** $\to$ 调用 `record_reflection_and_unlock_pull` 当场置位 **`first_reflection_unlocked = 1`** $\to$ 恢复探索者。
- **第三幕：`37% ~ 70%` 开放定向 Pull 期**：探索者自主调用 `query_library_catalog(scope="ALL")` 查内外两翼与 `read_lineage_graph`（含翻阅本脉祖先手记与 `lineage_dead_ends` 全量表）。
- **第四幕：`70%`（`350k`）或 `Cost Note` 停笔单写者交接**：
  - 唯有一对一 `lineage_companion` 拥有 `submit_node_handoff` 写权；提炼 `<2000` 字客观 A/B 双栏手记 + 遗嘱 + **必填 `<100` 字 `mechanism_summary`** + `evidence_grade` + 本代 `dead_ends` 列表写入数据库，节点状态置为 `AWAITING_TRIAGE`；
  - 仪器返回 `INSTRUMENT_ERROR` 或 `INFRA_ERROR` **绝不计入探索者失误**，仅将探索者自身 `CANDIDATE_ERROR` 及经盲审 `REVISE` 退回的异议转交后续分诊与看板。

## 二、G3 看板解耦、`lineage_dead_ends` 与“3 真相 + 2 视图”协调

### 2.1 解除“2200 字硬顶 vs 历代全量只增不忘”的逻辑死结
1. **维持现行增量看板骨架，不引入代码硬拼新复杂度**：伴随助手仍采用 **`新看板 = 旧看板 + 最新一页手记`** 增量改写并调用 `save_lineage_briefing`，维持实测边界可验证性。
2. **真相与视图职责切分（消除矛盾）**：
   - **“历代全量死胡同只增不忘”的物理载体**是底层的 **谱系 DAG（`lineage_nodes`）+ 结构化只追加表 `lineage_dead_ends`**（字段：`dead_end_id, question_id, branch_id, node_id, category('SCIENTIFIC_REFUTATION' | 'IMPL_FAILURE' | 'ENV_FAILURE'), scope_condition_md, failure_mechanism_md, bound_obs_id, created_at`）。伴随调 `submit_node_handoff` 时顺带结构化写入本代新排除的死胡同条目；
   - **表层《状态看板》**只强制校验唯一硬限制 **`total_chars <= 2200`**（原五段字数 `200/400/350/650/400` 降格为**软参考配比**，允许伴随按当轮需要挪用，严禁 `[:2000]` 截断）；
   - **看板第 4 段新定位**：精选与当前第 3 段核心矛盾**最直接相关的 Top-K 条反例边界** + 一行全表索引提示（例如：`本脉共沉淀 N 条历史已排除项，37% 解锁后可调 read_lineage_graph(view="dead_ends") 查阅全量`）。

## 三、分支级极简调度、无豁免学派刚性分流与四级分诊

### 3.1 依赖关系极简化（取代题级并集死锁 — G1 定案）
1. **可选全局策略题序 `question_order`**：仅在 Parse 0 表单由人类可选填（默认空全并发）；控制面在前序子题出现至少 `1` 条 `goal_coverage="FULL_GOAL"` 的活跃 `L3`（或被人类显式标记放行）时解锁下一子题，不做复杂依赖图推导。
2. **分支级确定性前置 `requires: list[str]`（只锁本分支，永不跨分支取并集）**：后勤建分支或执行 `fork_branch` 时可选填系统可确定性查库的前置 ID（**仅限两类**：① `L3-###` 须处于 `ACTIVE`；② `OBS:<instrument_id>:PASS` 须存在有效通过观测；禁填无权威来源的自由文本）。调度器**仅阻断声明了未就绪 `requires` 的那一条分支**；若某分支开跑后前置 `L3` 被撤回，标记该分支 `premise_revoked = true`（不强杀运行中会话，待其交接时转 `LEVEL_4B` 处理）。

### 3.2 方法族谱动态维护与“无豁免”学派聚拢打散（G2 + 四.4 定案）
1. **机制分类权归后勤（防改名撞车）**：`submit_node_handoff` 强制提交 **`mechanism_summary`（`<100` 字，只述底层数学/物理机制、不变量或归约框架，严禁写指标结果）**；后勤 `triage_node` 对照《方法族谱登记册》决定将分支归入已有 `family_id` 还是新立正交学派。
2. **开局不做强凑 2 路线硬卡**：Parse 0 有多少人类提示思路就先起多少路（可留空由控制面起手分流），**多样性改由运行中的聚拢规则持续强制保障**。
3. **无豁免刚性聚拢打散（采纳用户删去 `>= 4` 与删去高产豁免的双重裁决）**：
   - 控制面按子题统计活跃分支在各学派的分布；
   - **精确触发条件**：对任意子题，只要出现**同一学派下聚拢了多个活跃分支（`branch_count_in_family >= 2`）且该学派在当前子题的占比超过半数（`branch_count_in_family / total_active_branches_in_question > 0.50`）**，立即发出 `FAMILY_CONCENTRATION` 事件唤醒 `logistics_coordinator`；
   - 后勤必须立即抽调超出半数的冗余分支进行 `orthogonal` 正交重定向（调往未充分探索学派、阻塞已解除旧学派或新立正交机制）——**不设“近期有 L1/L3 产出就豁免”的后门，死保高并发多路探索，严防局部微调刷分制造虚假繁荣吞噬全部槽位！**
4. **两级公平分配 & 跨线学派阻塞**：并发槽位先按子题公平、再在子题内按学派公平分配；`LEVEL_4B` 默认只阻塞触发缺引理的本脉及其同前提子支，仅当后勤确认该 `blocking_lemma` 属整支 `family_id` 共同前置时才标为全学派 `BLOCKED`，但任何探索分支只要在 `fork_branch` 声明实质绕开方案 `new_mechanism_note` 即可随时重开该学派；**`Cross-Draft` 交叉授粉仅当双方学派各自至少已有 `>= 1` 条已入库 `L3` 后才予放行**（等价归约标注为 `EQUIVALENT_REDUCTION`，不计入突破）。

### 3.3 四级认知分诊与五车道复苏（v3.0 精准定义）
后勤 `triage_node` 收到 `AWAITING_TRIAGE` 后先过滤平台误差（凡属 `INSTRUMENT_ERROR / INFRA_ERROR` 绝对不消耗任何修补次数或停滞计数），随后裁决：
- **`ROUTINE_CONTINUATION`**：正常局部进展或局部参数否定，`VALID` 继续原分支推进；
- **`LEVEL_1`（送盲审）**：满足可核验性门槛（不限于布尔 `passed=1`，见 `agent_kb/03`）$\to$ 备份物理快照至 `<workspace>/snapshots/<branch_id>/retained_candidate/`，分支置为只读冻结 **`PENDING_REVIEW`** 推入中央图书馆 `STAGE1_BLIND`（若判 `REVISE` 则解锁回 `ACTIVE_REVISING` 返工）；
- **`LEVEL_2`（候选代码崩溃原地修补）**：`CANDIDATE_ERROR` 锁定研究方向，从物理快照恢复工作区原地修补（上限 3 次）；**满 3 次仍败写本脉 `lineage_dead_ends` + 退回健康祖先（不再写入公共图书馆 `L2`！）**；
- **`LEVEL_3`（偏科/反例/无标尺特异保护）**：单维或机理特异突破，先查防伪迹后单开保护线支持进一步验证；
- **`LEVEL_4A`（真实证伪 / 结构阻碍）**：需带严密反例或阻碍证明 $\to$ 同事务将分支置为只读冻结 **`PENDING_REVIEW`**（非永久封死！）送盲审：若盲审返 **`REVISE`** 则回切 `ACTIVE_REVISING` 允许原分支补全反例/证明；唯有终判确证 `ACCEPT*`（入 `L3`）、`REFUTED`（入 `L2`）或 `REVISE` 超限时才永久 **`SEALED`**；
- **`LEVEL_4B`（缺失定理级引理/前置条件阻塞）**：记 `reopen_condition` 暂停进 `Ready Queue`，并通知 `Auditor` 按需从残骸中打捞独立可用中间引理。
- **全局停滞五车道（`Station Stagnation Protocol`）**：当连续非突破交接（含主线空转）达阈值（默认 `8` 次，或全员阻塞）时，唤醒后勤通过 `dispatch_stagnation_five_lanes` 将活跃分支打散编入 `EXPLORATION / EXPLOITATION / REVIVAL / UNDERSTANDING / STRATEGY` 五互斥车道继续攻坚（在未过 `min_commitment_window` 前禁止以停滞为由提前交差！）。
