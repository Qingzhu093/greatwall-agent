### 1.1 宿主定位与无状态事件唤醒铁律
1. **极薄确定性总线（`ctx.agents.create()`）**：宿主主循环（开源 `DSH` Cordis Control Plane）仅监听客观数据库事件，不持有任何科学判断，不经由 `dsh-subagent`（规避 `maxDepth=1 / maxActiveSubagents=8` 瓶颈），直接以 **`ctx.agents.create({ sessionId, meta: { cwd }, setup })` + `agentCtx.tools.restrict()` + `handle.dispose()`** 拉起全部 **7 大角色契约** 的一次性短无状态会话，写回 SQLite 后立刻销毁，**工作区磁盘严禁产出任何流程审批 `.md` 公文**。
2. **隔离靠沙箱，绝不靠砍工具（v3.0 沙箱平权原则）**：
   - 过去仅探索者保留了 `pwsh`，却把 `library_verifier`（盲审官）物理裁剪为 `[]`（**0 个原生工具**），导致盲审只能瞪眼读文字、无法跑 Python/SymPy/Lean 4 验证脚本；
   - **v3.0 铁律**：所有需要计算或复核的角色均配置**OS/进程级独立隔离沙箱**——把数据库本体、隐藏校准/验证集、未授权 B 栏及他人工作区物理封死在沙箱之外，而在各自隔离沙箱内部**向探索者、工造司、盲审官大方开放真实动手工具（`read / pwsh / bash` 及对应语言/证明器插件）**！

### 1.2 Parse 0 六项启动表单 & “制度自闭环 vs 口径红灯”准则
1. **Parse 0 极简人机对齐**：开局由工造司起草以下 **6 项启动表单**，人类开跑前花费约 2 分钟审阅修改确认（存入 `parse0_contract` 表），即进入无人值守：
   ① 核心问题陈述与“什么算完成”（含部分交付/证伪是否算完成）；
   ② 子题划分与可选 `question_order`（默认空）；
   ③ 子题已有仪器、已知金/毒校准样本与指标方向（全部可留空）；
   ④ 已知候选思路提示（可留空，不强凑两条互斥路线）；
   ⑤ 总预算与**最短投入时间（`min_commitment_window`）**；
   ⑥ 预期终局交付形态。
2. **常规争议绝不打扰人 × 无人值守亮红灯续跑铁律**：
   - 分支合并、审稿打回（`REVISE`）、局部边界收缩等正常问题由既定制度自闭环，绝不弹窗问人；
   - 仅当出现**题目根本目标或验收标准本身存在重大歧义**时发出人类通知，在无人值守期间**严格按原已签口径继续跑（绝不挂起空耗或停机）**，同时在 `compliance_alerts` 与 WebUI 亮起 **`ALERT_AMBIGUOUS_SPEC` 红灯**等待人类事后人工处理。

## 二、极简数据底座：“3 个唯一真相（Append-Only）”与“2 个派生视图”

1. **真相 ①：观测账 (`Obs` / `observations`)** —— 仅 `official` / `heavy` 档仪器调用写入结构化凭证；严格绑定 `(instrument_id, instrument_version)` 与四态 `status`（`OK / CANDIDATE_ERROR / INSTRUMENT_ERROR / INFRA_ERROR`），`probe` 档仅返诊断日志不入 `Obs`。
2. **真相 ②：谱系 DAG + 结构化死胡同表 (`lineage_nodes` + `lineage_dead_ends`)** —— 各门派私有实验记录本（原 `L1` 合一至此）。每代退场写下一页 `<2000` 字客观 A/B 双栏手记 + 遗嘱 + `<100` 字 `mechanism_summary` + `evidence_grade`（`NONE / ARTIFACT_ONLY / MEASURED`）；所有已排除条件与失败机理同步只追加写入 **`lineage_dead_ends`** 表（承担“历代全量只增不忘”的物理归档义务）。**跨门派物理不可互看。**
3. **真相 ③：中央图书馆（两翼物理分表）** ——
   - **左翼·外藏 `external_literature_cards` (`[R###]`)**：`0%` 起全程开放 Pull，显式标定为**未经本系统实证复验的外部资料摘要**；
   - **右翼·内藏 `internal_research_ledger`（`L3_VERIFIED` 确证库 & `L2_FAILURE_RECORD` 否定雷达）**：经隔离盲审沙箱实测通过入 `L3`（**含带上 `NEG_COUNTEREXAMPLE / BARRIER_PROOF` 标签的严格证伪反例与障碍定理**）；被证伪失败路线或 2 轮 `REVISE` 超限未解异议入 `L2`；工程修补报错绝不进图书馆。
4. **视图 ①：谱系状态看板 (`Briefing`, `<= 2200` 字)** —— 维持“伴随拿旧看板 + 最新一页手记增量合成”架构（`max_briefing_chars = 2200` 硬上限，五段配比仅为软引导）；第 4 段定位为当前相关精选死胡同摘要 + `lineage_dead_ends` 总条数按需查表索引。
5. **视图 ②：图书馆两级目录卡** —— `query_library_catalog`（目录卡）$\to$ `get_library_entry`（全文详情）。

## 四、无状态高熟练度的四把工程手术刀
1. **角色盲盒裁剪**：探索者只看到眼前实验、看板、遗嘱与 5 个科研窄工具，彻底剥离制度术语干扰。
2. **JIT 工具回执动态路标（`next_step_guidance`）**：所有 MCP 回执尾部由服务端确定性输出下一步动作提示。
3. **百字工具速查表 + 单行合法 JSON 调用范例**：从 Schema 层消灭参数格式错误。
4. **`<worktree>/tools/` 清单注入 + `Retained Candidate` 物理快照接力**：聊天历史随会话销毁，代码资产、物理快照与结构化谱系记忆代代累积。
