## 一、极薄无偏见事件总线与全员无状态调用

### 1.1 为什么宿主必须“极薄、确定性、零科学偏见”？
长周期多智能体系统一旦设立常驻对话的“超级总管 Agent”，会在几十轮后陷入三大崩盘：对话膨胀失忆、疯狂在磁盘编写无实质价值的行政审批 `.md` 文件、以及凭主观猜测越权指挥底层解法。

因此，长城 V6-Up 确立**“有状态的搜索，无状态的智能体（Stateful Search with Stateless Agents）”**核心原则：
1. **宿主事件总线（DSH Cordis Control Plane）完全确定性**：不持有科学观点，不经由嵌套子代理派单树（规避最大深度 1 与并发上限 8 的宿主约束），直接调用 DSH 原生 **`ctx.agents.create({ sessionId, meta: { cwd }, setup })` + `agentCtx.tools.restrict()` + `handle.dispose()`** 调度全部 **7 大角色契约**。
2. **跨代零常驻短会话闭环**：5 个治理角色每次唤醒均为一次性无状态短会话（Push 视图 $\to$ 按需 Pull 真相 $\to$ 调 1–3 次窄工具写库 $\to$ 立即销毁释放内存与槽位）；一线探索单元的一对一伴随助手仅在**单个探索节点内**以暂停续传方式复用同一会话（`PRE_SPAWN -> 37% -> 70%`），**节点完结即彻底销毁，绝不跨代常驻**（若遇进程重启或崩溃仍可无状态冷启动兜底）。**全过程在工作区磁盘零过程审批 `.md` 文件。**

### 1.2 沙箱平权哲学：隔离靠沙箱边界，绝不靠砍计算工具
数据防泄密与防作弊依赖操作系统权限（Windows DACL / 低权限子进程域）与 Cordis `tools.guard` 的 `realpathSync` 路径白名单，而非把需要验证事实的角色阉割成纯文本读者：
- 数据库本体 `greatwall.db`、隐藏校准/保留集 `_hidden_*`、物理快照 `snapshots/` 与持久化产物 `eval_artifacts/` 全部隔离在工作区外部的 `$PLUGIN_DATA/workspaces/<ws_hash>/`；
- 在严格封闭的受控沙箱内部，**一线探索者（`explorer`）、科研仪器科（`works_engineer`）与同行盲审官（`library_verifier`）均按平台开放真实执行工具**（Windows 下为 `pwsh`，类 Unix 下为 `bash`，配 Python/SymPy/Lean 4 环境），让科学探索与同行审稿都建立在实跑验算之上。

### 1.3 Parse 0 六项人机启动表单与“无人值守红灯续跑”准则
1. **Parse 0 极简人机对齐**：开局由工造司起草 6 项核心配置，人类开跑前审签落入 `parse0_contract` 表即进入全自动无人值守：
   ① 核心问题陈述与“什么算完成”（明确部分成果、严格证伪是否算完成）；
   ② 子题划分与可选策略题序 `question_order`（默认空并发）；
   ③ 已有仪器、已知金/毒校准样本与指标方向（全部可留空，支持 0 判定器开放课题）；
   ④ 已知候选思路提示（可留空）；
   ⑤ 总预算与**最短投入时间（`min_commitment_window`）**；
   ⑥ 预期最终交付形态。
2. **常规争议自闭环 vs 口径歧义红灯续跑**：
   - 分支合并、审稿退回返工（`REVISE`）、结论适用边界收窄（`ACCEPT_NARROWED`）全部由系统内置流程自动消化，不打扰人类；
   - 仅当运行中发现**人类原始题目目标或验收口径本身存在重大歧义**时，向 `compliance_alerts` 写入 **`ALERT_AMBIGUOUS_SPEC`** 并在界面亮起红灯留待人类事后裁决；与此同时，**事件总线严格按原已签口径继续推进，绝不停机死等**。

## 二、极简数据底座：“3 个唯一真相 + 2 个派生视图”

全系统贯彻单一数据源（Single Source of Truth），真相只追加不覆写，视图可随时从真相无损重建：

1. **真相 ①：观测账（`observations`）** — 仅 `official` / `heavy` 档仪器调用写入的客观科学收据；严格绑定 `(instrument_id, instrument_version)` 与四态 `status`（`OK / CANDIDATE_ERROR / INSTRUMENT_ERROR / INFRA_ERROR`）。高频 `probe` 档仅写轻量诊断日志表，不污染观测账。
2. **真相 ②：谱系 DAG 与结构化死胡同表（`lineage_nodes` + `lineage_dead_ends`）** — 每个研究门派私有的实验记录本。每代退场由一对一伴随助手独占单写一页 `<2000` 字客观 A/B 双栏手记 + 遗嘱 + `<100` 字 `mechanism_summary` + `evidence_grade`；本代所有已排除条件边界同步只追加写入 **`lineage_dead_ends`** 表（承担“历代全量只增不忘”的物理归档）。**跨门派物理不可互看。**
3. **真相 ③：中央图书馆（两翼物理分表）** —
   - **左翼·外藏 `external_literature_cards` (`[R###]`)**：外部文献与定理参考，显式标定为“未经本系统独立复验的参考摘要”，**从 `0%` 起全程开放 Pull**；
   - **右翼·内藏 `internal_research_ledger`（`L3_VERIFIED` 确证库 & `L2_FAILURE_RECORD` 否定雷达）**：经盲审沙箱实测通过入 `L3`（含带类型标签的严格反例与障碍证明）；确证证伪或返工超限未解异议入 `L2`；工程报错不入图书馆。**`0–37%` 物理锁定，`37%` 元反思后开放 Pull。**
4. **视图 ①：谱系状态看板（`lineage_briefings`, `<= 2200` 字）** — 伴随助手在下代探索者启动前按**定额滚动重压缩** $\text{Rewrite}_{\le 2200}(\text{旧看板},\; \text{刚退场最新一页手记})$ 重写的轻量启动扉页（非字符串累加：总长硬限 `<= 2200` 字，段 5 整体替换最新遗嘱、段 3 覆盖刷新当前矛盾、段 2 合并覆写最新快照、段 4 仅留当前相关 Top-K 死胡同并附 `lineage_dead_ends` 全表索引）。
5. **视图 ②：图书馆两级目录卡** — 先调 `query_library_catalog` 浏览 `<= 350` 字独立摘要目录卡，再按 `entry_id` 调 `get_library_entry` 定向拉取全文详情。

## 四、无状态启动高熟练度的“四把工程手术刀”

1. **角色盲盒与极简工具裁剪**：每个角色只看到自己的局部闭环与 3–5 个窄工具，系统 Prompt 中不夹杂与本角色无关的宏观制度名词。
2. **JIT 工具回执动态路标（`next_step_guidance`）**：服务端在每次工具返回的 JSON 尾部确定性注入下一步动作提示，替代开场背诵长文档。
3. **百字速查表 + 单行合法 JSON 范例**：所有挂载工具在模板与 JSON Schema 中给出完整类型、合法枚举与单行示例，消灭参数试错。
4. **资产代际持久化**：无状态清空聊天废话，而 `<worktree>/tools/` 模块清单由宿主启动自动扫描注入，代码里程碑靠物理快照（`Retained Candidate`）代代接力。
