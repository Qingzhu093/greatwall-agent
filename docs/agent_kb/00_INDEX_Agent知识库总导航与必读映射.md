## 二、全项目二十大“低品味/实习生反模式”红灯清单 v2.0（看到即判定不合格）

### A 组：顶层拓扑与制度基线十大红灯（一轮确立）
1. **中心化星型太上皇反模式**：把主循环或后勤总管写成统领监察委、中央图书馆、工造司和探索者的单一集权 Orchestrator（违背一委三部平行制衡）。
2. **CTF 密码预注册反模式**：为防模型越权，发明 20 位高熵随机 `session_id` 密码锁和繁琐注册-切换状态机——科研探索者不是黑客，用宿主 `tools` 白名单 + 语义可读身份标识（`branch_id/node_id/role`）足矣。
3. **伴随助手双模阉割反模式**：把原本“一对一贴身协助一个探索者”的分身伴随助手，阉割成平时只返回空洞模板字符串、仅报错才拉起的残缺工具。
4. **`[:120]` 伪摘要与只读空壳图书馆反模式**：图书馆缺 `Archive Surveyor` 外部文献/算子卡正式入库接口、或在 `read_depth="abstract_only"` 时拿 `scope_full[:120]` 截断前 120 字符冒充摘要！
5. **不合成跨代看板反模式**：`get_lineage_briefing` 只查单个节点字段或返回空串，未将跨代核心直觉、已证实前提、历史全量已踩反例与近 1–2 代遗嘱动态增量合成为 `~2000` 字净室看板。
6. **空壳方法族谱与兄弟失忆反模式**：声称有《方法族谱登记册》与兄弟防撞车，实则数据库无正式 Registry 表或派生前根本不比对已有分支思想机制。
7. **硬编码 `False` 全局停滞看门狗反模式**：`check_stagnation()` 不从真实分诊历史追踪连续非 L1 交接次数或全员 L4 阻塞状态，直接偷懒返回 `False`。
8. **30 行“保安条例式”干瘪 Prompt 反模式**：角色 Prompt 只写二三十行“禁止越权、遵守格式”的空话，完全缺失 `Station` 11 类元反思题库、`AgentDiscover` 图搜索元认知策略、`OpenAI CDC` 7 类结构漏洞红队清单等核心科学灵魂。
9. **将具体学科公式硬编码进通用底座反模式**：把某道方程物理约束写死在 `isolated_runner.py` 等通用基础设施里，破坏“通用容器 vs 工造司动态课题验证钩子”的硬解耦。
